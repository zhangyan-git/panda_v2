# gateway-service

The gateway forwards `POST /v1/auth/login` to the account service, protected user requests to the user service, and protected merchant/admin requests (`/v1/merchant/`, `/v1/admin/merchants`, `/v1/admin/stores`, `/v1/admin/merchant-accounts`) to the merchant service. Configure `ACCOUNT_SERVICE_URL`, `USER_SERVICE_URL`, and `MERCHANT_SERVICE_URL` with downstream base URLs (for example, `http://account-service:8080`, `http://user-service:8080`, and `http://merchant-service:8080`). The gateway preserves selected client headers, strips internal identity headers, and passes downstream responses safely; timeouts return 504 and connection failures return 502. Other authenticated `/v1/` routes return 501.
